= theory Unit

Theoretical write-ups, sorted by discipline. Theoretical claims should reference
established academic or technical formalisms.

* `computing/trope-theory-and-neural-representation.adoc` — reading learned neural
  features as tropes (abstract particulars); the estate's loss/deception effects as a
  diagnostic vocabulary over superposition, polysemanticity, and the binding problem.
  A provisional position paper.

* `formalisms/defining-o5-veridicality-oracle.adoc` — a proposed calculus §10 entry
  for O5 (the veridicality oracle): an IR-relative undecidability remark plus an
  oracle interface (O5-1..3) for deployments. Proposal only — normative home is the
  trope-checker calculus, owner-ratified.

* `ontologies/swapping-as-grade-commutativity.adoc` — a first formal image of the
  swapping/transposition objection: the ratified commutativity of `▷` as
  swapping-invariance, paired with the numerical-identity axis to dissolve the
  dilemma. Provisional research note; the first of the WP-1 trio.

* `ontologies/piling-as-labelled-fusion.adoc` — the second of the WP-1 trio: the
  piling/stacking objection through the `merge` coordinate (`Single ⊐ Fused(τ) ⊐
  Conflated`). Piling is honestly aggregable (`Fused`) and record-constrained, never
  ontologically barred — so the "a bar smuggles in universals" horn fails. Provisional.

* `ontologies/resemblance-regress-on-the-record-axis.adoc` — the third (and most
  tentative) of the WP-1 trio: Russell's resemblance-regress via the `record` axis.
  Not a refutation — the ontological regress is left to the internal-relations reply —
  but a relocation: the record axis separates the resemblance *relation* (self-grounding)
  from the resemblance *claim* (warranted, terminating at the O5 world-access boundary).
