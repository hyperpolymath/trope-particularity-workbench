= Computing Theory

Theory write-ups on the computational side of trope-particularity.

* `trope-theory-and-neural-representation.adoc` — a position paper: learned neural
  features as tropes (abstract particulars), and the estate's nine loss/deception
  effects as names for known network pathologies (superposition, polysemanticity, the
  binding problem). Framed as research directions and hypotheses, not results.
