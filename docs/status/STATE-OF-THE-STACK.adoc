== The five-repo map

Vocabulary track: trope-particularity-workbench → haec → trope-checker (verdict).
Store/query track: haec → vocarium → hermeneia → trope-checker (verdict).
trope-checker depends on nothing (HC-1); the workbench depends on nothing;
vocarium and hermeneia meet at the M2 StoreProvider adapter (vocarium ADR-0002:
wire, do not link).

== Known gaps

* A2ML machine-readable files are still present in haec, hermeneia and vocarium
  (retired in this repo and in trope-checker); retirement is written up as an
  issue per repo, not done in Phase 0.
* vocarium's gate pins checker commit `69221ad6`, which predates the spec v0.2
  consolidation; the pin is to be bumped once Phase 0 lands upstream (issue).
* This repo's GitHub Pages (trainer) run has been queued since 2026-10-06 and a
  Secret scan run was cancelled; both are repository settings, owner-only.
* `trope-checker`'s `just build-lean` was not run in the Phase 0 session (no
  Lean toolchain reachable there); its `proofs.yml` CI job is the attestation.
