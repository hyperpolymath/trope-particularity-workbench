= Agent Instructions
:toc: preamble

Methodology-aware configuration for AI agents. The repo deed
`trope-particularity-workbench_chora.deed` names this directory in its
`(agentic (methodology :instructions-dir …))` clause.

== Current state

This directory holds no instruction files. The A2ML methodology, coverage and
debt files that used to live here were retired with the rest of the A2ML tree;
they are frozen at https://github.com/hyperpolymath/trope-particularity-workbench/tree/b18eb67dcf10e80d3560b0468a7a85c484231f02/.machine_readable/bot_directives.

== Relationship to Other Files

* The repo deed's `(agentic …)` clause says WHAT agents can do (permissions, integrity gating).
* `bot_directives/` says HOW agents should work (methodology), when files are added here.
* `CLAUDE.md` says how Claude specifically should work (Claude-specific).
