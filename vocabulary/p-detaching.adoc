= `p-detaching`
:toc: macro

*Family:* effect  *·  Arity:* one  *·  Veridicality:* faithful

*Grade (calculus):* fate(quality) `Present`, other fields `Dropped`, bond `Severed`; the type becomes `FloatingQuality`.

== Definition

The quality severed from its bearer — the constitutive quality–bearer bond broken. A trait floating free of whose it was.

== Discriminating test (vs `p-projecting (dropping the bearer)`)

Is the bearer-loss a clean named drop or a constitutive severance? Projecting away the bearer leaves `Withheld` (recoverable in principle); detaching leaves `Severed` (irrecoverable) and changes the type to `FloatingQuality`, so any downstream use needing a bearer fails to typecheck.

== Worked example

A single vivid line is lifted from an interview and shared on its own — no speaker, no question, no surrounding context. The words are intact; the tie to whoever said them is cut.
