=== [Unreleased]

==== Added

* A stack coherence gate (`tests/check-stack-coherence.sh`, `just
  stack-coherence`). It reads the five trope-stack repositories and fails when
  they disagree about a shared fact: the IR schema and version, the five-repo
  map, the checker commit each sibling builds against, the revision of the
  shared scan workflow, root documents a README cites, template identity left
  in a repository's description, the `coordination` value, and any claim listed
  in `tests/stack-coherence/retired-claims.tsv`. It writes nothing. Run on the
  five `main` branches on 2026-11-17 it reports 6 of 10 checks in disagreement;
  the fixes belong to the sibling repositories. The live gate runs on pushes to
  `main`, weekly and on demand. Its self-test
  (`tests/check-stack-coherence-selftest.sh`, 19 cases: one planted
  disagreement per check, three controls) runs on every pull request.
* A survey of where Vocarium could serve beyond the trope stack
  (`docs/theory/formalisms/vocarium-survey.adoc`): the Palimpsest licence's
  logic, the chora registry, VeriSimDB's consonance subjects and the cadastre.
  Four experiments, run on the built store engine and the shipped checker, with
  fixtures in `examples/survey/` and a script that re-runs them (`just survey`,
  12 results). It records one known false acceptance (trope-checker issue 125,
  shown on a consent scope), two gaps in Vocarium (no revocation; the emitted IR
  carries no warrant), a comparison of Vocarium's warrant with the
  epistemic-types levels, and a proposed theorem on the level of a verdict,
  stated and not proved. Nothing is adopted.

==== Changed

* The repository is now documentation only. The inherited RSR template
  scaffolding (ABI/FFI seam, proof stubs, container and build trees, template
  docs, 19 template workflows) is removed. The authored vocabulary, trainer,
  map, examples, theory papers, whitepapers and proposals are unchanged.
* GitHub Pages now serves the particularity trainer as the site index, with the
  pipeline map beside it: https://hyperpolymath.github.io/trope-particularity-workbench/
